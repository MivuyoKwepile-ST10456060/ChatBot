Cybersecurity Awareness Chatbot

A C# console-based chatbot designed to educate users about cybersecurity best practices such as password safety, phishing awareness, and safe browsing.

---

Features

- Interactive chatbot conversation
- Colored console interface with typewriter effect
- Cybersecurity-focused responses
- Voice greeting using audio playback (NAudio)
- Keyword-based response system
- User profile tracking (name & interactions)
- ASCII art cybersecurity-themed header
- Input validation and error handling

---

Technologies Used

- C# (.NET 8)
- Console Application
- NAudio (for audio playback)
- Git & GitHub (version control & CI)
